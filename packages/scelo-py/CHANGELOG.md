# Changelog

## 0.1.0 (2026-08-23)

First release: the Scelo IDE brain layer as a Python library. 230+ public
names under `import scelo as sc`; numpy + pandas only; a `Table` DataFrame
that carries title, basis, notes and provenance; the `df.sc` accessor; the
`scelo` command line; parity with the IDE's typing, cleaning, actuarial
tables, reserving bridge and WMTR engine; a client for the bundled swarm.
